# Everything under python/hotpot — run.py and all six processes. Install
# once for the whole tree:
#
#     pip install -r python/requirements.txt
#
# websockets backs core/web/server.py's staff view (doc section 12): the
# sync flavour (websockets.sync.server / .client), not the more commonly
# documented asyncio one, because the rest of this codebase is threaded
# and the sync API matches that model directly. See that file's docstring.
#
# Lower-bounded at the version this was built and tested against (16.1),
# not pinned exactly: core/web/server.py relies on the Request/Response
# based process_request() hook, which is the part of the API most likely
# to differ across versions, so an untested older release is a real risk
# rather than a formality.
websockets>=16.1

# pyserial backs core/scale.py's load-cell thread (doc section 9.5) — the
# XIAO's `raw <c0> ... <c7>` lines at 115200. It is imported inside
# scale.py's `_open_serial()` rather than at module scope, so the parse,
# the median filter and the settle window stay importable and testable on
# a machine with neither pyserial nor a XIAO; only opening a real port
# needs this installed.
#
# Lower-bounded at the version the rig was verified against (3.5, on
# COM5, 2026-08-11). 3.5 is also where `Serial.readline()`'s timeout
# behaviour — a whole-call deadline that returns whatever arrived, which
# is what bounds that read and lets stop() be prompt — is the documented
# one.
pyserial>=3.5
